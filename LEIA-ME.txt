SOFISTICATTO FINANCEIRO — VERSÃO MODULAR COM COTAÇÕES

ARQUIVOS PARA SUBSTITUIR/ADICIONAR NA RAIZ DO GITHUB:
- index.html
- styles.css
- financeiro.js
- clientes.js
- transportadoras.js
- cotacoes.js
- whatsapp.js
- dashboard.js
- notificacoes.js
- service-worker-notificacoes.js (se estiver no pacote)

MANTER:
- pasta api/
- api/enviar-email.js
- package.json atual

SUPABASE:
1. Abra SQL Editor.
2. Execute sql_modulo_cotacoes_modular.sql.
3. Aguarde a mensagem de sucesso.

ORDEM DOS ARQUIVOS:
O index.html já carrega os arquivos na ordem correta. Não acrescente os scripts
manualmente, pois isso poderá duplicar constantes e funções.

CADASTRO PARCIAL:
- Se o cliente só tiver o nome, preencha os dados da cotação normalmente.
- Ao salvar, o sistema pergunta:
  OK = atualizar/substituir o cadastro;
  Cancelar = usar somente nesta cotação.
- Se o cliente ainda não existir, também pergunta se deseja cadastrá-lo.

PUBLICAÇÃO:
1. Envie todos os arquivos para a raiz do repositório.
2. Aguarde o deploy da Vercel.
3. Pressione Ctrl + F5 no computador.
4. No celular, feche e abra o Chrome novamente.

ATUALIZAÇÃO V9 — PREENCHIMENTO AUTOMÁTICO:
- Nova opção padrão: “Atualizar campos vazios automaticamente”.

ATUALIZAÇÃO V10 — SEM PERGUNTAS INDIVIDUAIS:
- O modo “Atualizar campos vazios automaticamente” não abre mais confirmação cliente por cliente.
- CNPJ/CPF exato: atualiza campos vazios automaticamente.
- Nome exato: atualiza campos vazios automaticamente.
- Nome muito semelhante (88% ou mais): atualiza campos vazios automaticamente.
- Nome duvidoso abaixo de 88%: cria novo cadastro em vez de alterar um cliente possivelmente errado.
- As opções manuais continuam disponíveis caso queira revisar individualmente.
- Não precisa executar SQL novo.
